# HAK Lương Offline V10.4 — v2.0.24

Bản chỉ đổi trình bày file Excel mẫu nhập liệu. Không đổi công thức, dữ liệu, cấu trúc lưu trữ.

- **File mẫu nhập liệu đẹp hơn:** nút "Tải file mẫu" tạo file có tiêu đề nền xanh chữ trắng, cố định dòng đầu, bộ lọc, độ rộng cột theo nội dung, dòng ví dụ nền vàng kèm ghi chú "xóa dòng vàng rồi nhập dữ liệu thật", cột tiền có dấu phân cách nghìn, sheet Hướng dẫn tô màu, in A4 ngang.
- Tên sheet, tên cột ở dòng 1 và giá trị mẫu giữ nguyên nên nhập lại vào app vẫn đọc đúng; mã có số 0 đầu vẫn là chữ. Nếu thiếu thư viện ExcelJS, app quay về cách xuất cũ.
- Kiểm thử hồi quy mới: `template-xlsx`.

## Giới hạn còn tồn tại
- Bản này chưa được thử trên máy Windows thật. Nên cài thử với bản sao dữ liệu thật trước khi dùng cho kỳ lương chính thức.
- Chỉ phần file mẫu nhập liệu được làm đẹp; màn hình xem trước khi nhập Excel và các file Excel xuất ra chưa đổi.
