# HAK Lương Offline V10.4 — v2.0.58

Trạng thái: thử nghiệm có kiểm soát

Khắc phục lỗi P2.7 (T-13): cho phép đặt thư mục sao lưu JSON, thư mục dự phòng (mirror) hoặc Full Backup lồng/trùng nhau hoặc nằm trong `userData` / `backups`. Không sửa `main/storage-paths.js` (tệp khóa).

## Thay đổi
1. `LuongHAK_Offline/main.js`: trích hàm thuần `isNestedOrSame(a, b, pathMod, platform)` (so sánh không phân biệt hoa/thường trên `win32`) và bộ kiểm tra `checkDirConflict(target, excludeKind)` kiểm tra xung đột với `userData`, `backups`, `export`, `json` và các thư mục `SP.KINDS`.
2. Áp dụng `checkDirConflict` cho `paths-move`, `json-set-dir` và `backup-mirror-choose` (trả `{ ok: false, error }` khi vi phạm).

## Kiểm
- Test đỏ trước → xanh sau: `tests/unit/backup-dir-nesting.test.js` (2/2 ca đạt).
- Kiểm tra toàn bộ repo: `npm run check && npm run check:shared`.

## Giới hạn / chưa kiểm
