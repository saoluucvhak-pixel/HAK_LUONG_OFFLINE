# HAK Lương Offline V10.4 — v2.0.58

Trạng thái: thử nghiệm có kiểm soát

Khắc phục lỗi P2.6 (T-12): mở app luôn tạo bản sao lưu `startup` dù dữ liệu không đổi, và lịch sử bản chụp SQLite giữ 10 bản chung mọi nhãn khiến `startup` đẩy `daily`/`manual` ra ngoài. Không thay đổi `main/storage.js` hay các mô-đun khóa.

## Thay đổi
1. `LuongHAK_Offline/main.js`: chỉ gọi `storage.backup("startup")` khi `!storage.changedSinceBackup || storage.changedSinceBackup()`.
2. `LuongHAK_Offline/main/sqlite-storage.js`: sửa `pruneSnaps(d)` giữ tối đa `SNAP_KEEP` (10) bản chụp cho **từng nhãn** riêng biệt, giữ vĩnh viễn nhãn `sau-chot*` và `nam-YYYY`, và không bao giờ xóa bản mới nhất toàn thư mục.

## Kiểm
- Test đỏ trước → xanh sau: `tests/unit/sqlite-snapshot-retention.test.js` (3/3 ca đạt) và `tests/unit/sqlite-backup-snapshot-all.test.js` (7/7 ca đạt).
- Kiểm tra toàn bộ repo: `npm run check && npm run check:shared`.
