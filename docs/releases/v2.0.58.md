# HAK Lương Offline V10.4 — v2.0.58

Trạng thái: thử nghiệm có kiểm soát

Sửa tương phản tiêu đề cột bảng (`th`) đạt chuẩn WCAG AA ≥ 4,5:1 ở cả 4 giao diện (classic sáng/tối, luxe sáng/tối) — mục P3.2 / T-25. Chỉ sửa `LuongHAK_Offline/style.css`, không chạm các tệp CSS khóa (`ui/workspace-v104.css`, `ui/hak-enterprise-components.css`).

## Thay đổi
1. `LuongHAK_Offline/style.css`: đặt `th{color:color-mix(in srgb,var(--mut) 60%,var(--ink))}` để tiêu đề cột bảng trên nền `--th` đạt tỷ lệ tương phản ≥ 4,5:1.
2. `LuongHAK_Offline/tests/unit/contrast-aa.test.js`: bổ sung unit test kiểm tra tỷ lệ tương phản WCAG AA ≥ 4,5:1 cho `th` và `.hint` trên cả 4 biến thể giao diện.

## Kiểm
- `node --test tests/unit/contrast-aa.test.js`: 2/2 pass (T-25.1, T-25.2).
- `npm run check && npm run check:shared`: chạy sau khi hoàn tất.

## Giới hạn / chưa kiểm
- Chưa chạy kiểm tra trực quan Electron UI trên Windows thật trong phiên này.

## Tham chiếu đã đối chiếu
