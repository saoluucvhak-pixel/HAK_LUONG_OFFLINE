## Thay đổi (chỉ chuỗi ghi của tiến trình chính)
1. `main/sqlite-storage.js`: thêm `currentDoc()` — bản đang lưu đã phân tích (chỉ đọc) kèm sig. `save(text, parsed, rowsHint)` nhận chuỗi JSON từng dòng đã tính sẵn (chỉ dùng khi đúng đối tượng `parsed`).
2. `main/write-policy.js`: bản cũ lấy từ `currentDoc()` khi đúng sig (trước đây sau MỖI lần lưu phải đọc + phân tích lại toàn bộ dữ liệu); so "bảng có đổi" bằng chuỗi từng dòng thay cho băm cả bảng (cùng ý nghĩa: "[" + dòng.join(",") + "]" = JSON.stringify(bảng)); `rowsFor(parsed)` trả chuỗi dòng cho kho SQLite dùng lại.
3. `main/year-archive.js`: kiểm kho năm dùng `currentDoc()` thay vì phân tích lại toàn bộ (chỉ cần `_yearArchives`).
4. `main/sqlite-changeset.js`: so dòng dùng chuỗi đã tính sẵn nếu có. `main.js`: nối các phần trên.

## Giới hạn / chưa kiểm
- 5.000 NV: p50 đạt < 150 ms; **p95 ~161 ms, chưa đạt < 150 ms** (đỉnh do thu gom bộ nhớ khi phân tích JSON). Chưa tính phần giao diện (dựng văn bản ~67 ms + truyền IPC). Muốn thấp hơn nữa phải gửi phần thay đổi từ giao diện (giai đoạn 2, đổi đường IPC) — chưa làm.
