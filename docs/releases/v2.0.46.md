## Thay đổi
1. **Một màn, 5 khu, mỗi chức năng một lần:** (1) *Sao lưu ngay* — một nút + ô chọn loại: SQLite (mặc định) / Full Backup / JSON; (2) *Khôi phục toàn bộ* — một nút + ô chọn loại (gói Full Backup `.zip`/`.hakenc` hoặc file JSON); (3) *Tự sao lưu (SQLite)* — lịch hiện có; (4) *Thư mục* — MỘT bảng: SQLite (các bản tự động), JSON, Full Backup, dự phòng ngoài máy, chứng từ gốc, thư viện OCR, thư mục xuất file; (5) *Danh sách bản sao lưu & kiểm tra*. "Lưu trữ năm" giữ nguyên chức năng, đặt sau 5 khu. Phạm vi "Toàn bộ" ghi rõ: JSON không có chứng từ gốc và thư viện OCR.
2. **Bỏ trùng:** thư mục dự phòng (`mirrorDir`) chỉ chọn ở bảng thư mục (cơ chế chép + kiểm SHA-256 sẵn có); thẻ "Sao lưu ra ngoài máy" chỉ còn trạng thái chép (+ nút Chép ngay). Bỏ các nút "Tạo bản sao lưu ngay", "Tạo Full Backup", "Sao lưu ra file" (đã gộp vào khu 1).
3. **Chữ "giữ N ngày" lấy từ cài đặt thật** (`keepDaily`), không ghi cứng 60.
4. **Thư mục sao lưu JSON (mới):** khóa cài đặt mới `jsonDir` (chỉ thêm; mặc định `<dữ liệu>/json_backups`). "Sao lưu toàn bộ → JSON" ghi file `LuongHAK_JSON_YYYYMMDD_HHMMSS.json` vào đó (ghi tạm + **fsync** → kiểm SHA-256 → đổi tên; hàm `writeTextDurable` trong `main/restore.js`, có unit test `json-durable-write`), không qua hộp thoại tải về; "Lưu vào chỗ khác…" vẫn có. Đổi thư mục JSON: chép các bản cũ + kiểm SHA-256, không xóa nguồn, chặn thư mục lồng nhau/trùng thư mục lưu trữ khác. Mã ở `main.js`/`preload.js` (IPC `json-*`, `hakJson`); không sửa `main/storage-paths.js`/`main/storage.js` (tệp kế thừa bị CI so với bản gốc).
5. Kiểm "Kiểm tra" + "Mở" của bảng thư mục dùng được cho dòng JSON và SQLite.
